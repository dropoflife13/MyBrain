# M-02 — Cognitive Stats Engine (v1)

How we calculate the user's "Cortex Level" and Agent Mastery.

## Rules
- **Target Cap:** 20 rules per Agent is considered "100% Mastery".
- **Overclocking:** If a user exceeds 20 rules (e.g., 30 UX rules), the bar stays at 100% but glows Purple to indicate "Overclocked".
- **Grouped Dimensions:** (e.g., Empathy = PM + UX). Calculated by combining the totals of the grouped agents.
- **Gap Analysis:** Any Agent or Dimension below 30% is flagged as a "Blind Spot" requiring immediate attention.

## Essence
Quantify and visualize an operator's tacit knowledge density into actionable cognitive dimensions with clear blind-spot diagnosis and rewarding mastery feedback.

## When I reach for it
WHEN building any personal knowledge system, skill matrix, operator profile, or learning dashboard.

## How I apply it
1. Parse live markdown vault or rule definitions deterministically (`lib/stats.ts`).
2. Standardize target capacity at 20 rules per agent domain (`TARGET_RULES_PER_AGENT = 20`).
3. Aggregate the 5 core cognitive dimensions (Security, Systems, Empathy, Execution, Capacity).
4. Cap display fractions at `displayCount / target` to avoid arithmetic overflow.
5. Highlight Overclocked domains (`> 20` rules) with a signature purple glow and `100%+`.
6. Run Gap Analysis: flag any dimension `< 30%` as a critical blind spot and point the operator to the exact target file.

## Where it breaks
Breaks for public-facing apps where users do not own the underlying data, or strictly functional non-gamified enterprise administrative panels.
