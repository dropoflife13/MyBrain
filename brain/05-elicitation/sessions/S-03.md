# S-03 — Post-Build Excavation: Cortex v2.4 Engineering Journey, Anti-Overlap Deduplication & Live Sync

Artifact Archaeology (`A-06`) and Post-Mortem Excavation synthesizing the architectural lessons, failure boundaries (`breaks:`), and deduplication invariants discovered while building and polishing the Cortex v2.4 3D Knowledge Console (`app/page.tsx`, `app/console/page.tsx`, `components/Brain3D.tsx`, `components/NeuralLoader.tsx`, `app/api/brain/route.ts`, `lib/brain-parser.ts`).

## Part 1: What We Built & Why It Matters (`A-06`)
1. **Strict Pre-Flight Invariant (`BN-00`):** Coupled the Procedural Brain (`brain/`) with the 7-Agent Execution Suite (`agents/productmanageragent.md`, `uiuxagent.md`, `growthagent.md`, `systemsdesignagent.md`, `integrationagent.md`, `dbaagent.md`, `securityagent.md`). 2. **Earned Judgment via Blank-Slate Forking (`P-05`):** Configured public forks and `/brain-template.zip` to ship with all 7 Agent Gatekeepers intact (`status: active`) but `0 personal rules` (`status: empty`), requiring every adopter to run `Launcher L-01` (`THE-TEST.md`) to excavate their own engineering standards.
3. **Cinematic Route Architecture & Onboarding:** Separated the narrative landing page (`/`), the 360-node interactive 3D console (`/console`), the 7-Agent execution directory (`/agents`), and the 5-step beginner initiation guide (`/start`).

## Part 2: Bugs Hit, Root Causes & Architectural Fixes (Lessons Learned)
1. **[S-03.1 — `UI-07` / `RF-09` / `X-04`: OrbitControls Camera Snap-Back]:**
   - *Symptom:* 3D brain rotation stuttered and snapped back on every frame when `camera.position.lerp()` ran alongside `OrbitControls.autoRotate = true`.
   - *Root Cause:* `OrbitControls.update()` recomputes camera position from internal spherical coordinates (`theta`, `phi`, `radius`). Mutating `camera.position` directly while `autoRotate` is active creates two competing writers on the same transform.
   - *Rule Learned (`UI-07`):* Give `OrbitControls` exclusive ownership of continuous rotation (`autoRotate = true`, `autoRotateSpeed = 1.0`, `dampingFactor = 0.05`) and only lerp `camera.position` when `autoRotate` is paused (`isLockedOnNode`).
2. **[S-03.2 — `UI-08` / `RF-10`: Double Sequential Loading Screens & Premature Unmount]:**
   - *Symptom:* Clicking "Open Your Mind" showed a loader on `/` before navigating, followed by a second loader on `/console`; furthermore, unmounting `<NeuralLoader />` on `isGraphReady` (350ms) while fading the canvas on `isReady` (2500ms) left a 2.15s blank void.
   - *Rule Learned (`UI-08`):* Execute `router.push('/console')` immediately on CTA click with zero source-page loader; gate both the destination `<NeuralLoader />` unmount and the `<Brain3D>` opacity fade-in on the exact same composite boolean (`isReady = isGraphReady && minTimerDone`).
3. **[S-03.3 — `UI-09` / `TA-14`: Asymmetric Flexbox Headers & Unstyled Light Mode Panels]:**
   - *Symptom:* Using `flex justify-between` caused the center navigation/gate dock to shift off-center whenever the left brand pill and right control group had different widths; light mode left the 3D canvas and inspector sidebar dark.
   - *Rule Learned (`UI-09`, `TA-14`):* Enforce `grid grid-cols-[1fr_auto_1fr] items-center` with uniform `h-10` heights across all 3 header columns, and pair the dark obsidian theme (`#050505`) with a complete Architectural Blueprint Light Mode (`#f0f4f8` canvas, `#1e3a8a` navy rule nodes, `#cbd5e1` links, frosted `bg-white/90` HUD panels).
4. **[S-03.4 — `SO-08` / `H-06`: Hardcoded Parser Drift vs. Live Markdown Vault]:**
   - *Symptom:* `lib/brain-parser.ts` held a partial hardcoded copy of the vault (`VAULT_MARKDOWN_SOURCES`) that omitted 18 rules (`OP-03..05`, `OP-08`, `OP-10..12`, `TA-05..12`, `RF-04`, `RF-06`, `RF-08`), and `/api/brain` only patched the 18 parent document nodes while leaving the 341 synaptic nodes tied to the stale static strings.
   - *Rule Learned (`SO-08`, `H-06`):* Generate all 360 synaptic nodes dynamically from the live parsed `.md` files in `/api/brain`, keep the static fallback 100% synchronized with `brain/`, and run automated mechanical + anti-overlap validation (`check-vault.py` and `auditVaultConsistency`) so zero duplicate IDs, missing frontmatter, or unowned rules ever ship.
