# M-02 — Cognitive Stats Engine (v2 Weighted Scoring)

How we calculate the user's "Cortex Level" and Agent Mastery using evidence-weighted scoring.

## Rules
- **Confidence Weighting (`conf: X`):** Each rule contributes `1..5` points based on its `conf: X` tag (`conf: 1` or untagged = 1, `conf: 2` = 2, `conf: 3` = 3, `conf: 4` = 4, `conf: 5` = 5).
- **Target Cap:** 60 weighted points per Agent is considered "100% Mastery" (`TARGET_WEIGHTED_SCORE_PER_AGENT = 60`).
- **High Confidence:** If an Agent exceeds 60 weighted points, the bar stays at 100% (`100%+`) and glows Purple (`⚡ High Confidence`).
- **Unverified State:** If an Agent has `>= 10` rules with an average confidence `< 2.0`, it displays an amber **`⚠️ Unverified`** badge and triggers an **Unverified Knowledge** warning.
- **Grouped Dimensions:** (e.g., Empathy = PM + UX). Calculated by combining the weighted scores of the grouped agents (`2 × 60 = 120` pts).
- **Gap Analysis:** Any Agent or Dimension below 30% (or in an Unverified state) is flagged in the **Blind Spots** section.

## Essence
Quantify and visualize an operator's verified knowledge density by weighting rules according to real-world evidence (`conf: 1..5`), preventing shallow rule-padding and surfacing both low-coverage and unverified blind spots.

## When I reach for it
WHEN building any personal knowledge system, skill matrix, operator profile, or learning dashboard.

## How I apply it
1. Parse live markdown vault rules and extract `conf: X` weights deterministically (`lib/stats.ts`).
2. Standardize target capacity at 60 weighted points per agent domain (`TARGET_WEIGHTED_SCORE_PER_AGENT = 60`).
3. Aggregate the 5 core cognitive dimensions (Security, Systems, Empathy, Execution, Capacity).
4. Cap display fractions at `displayScore / targetScore` to avoid arithmetic overflow.
5. Highlight High Confidence domains (`> 60` weighted pts) with a purple glow and `100%+`, and flag Unverified domains (`>= 10` rules, `avgConfidence < 2.0`) with an amber `⚠️ Unverified` badge.
6. Run Gap Analysis: surface both Low Mastery (`< 30%`) and Unverified Knowledge blind spots.

## Where it breaks
Breaks for public-facing apps where users do not own the underlying data, or strictly functional non-gamified enterprise administrative panels.
